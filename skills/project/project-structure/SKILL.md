# Project Structure

## Purpose

Menjaga struktur project tetap mudah dipahami.

## Rules

- Ikuti architecture existing.
- Jangan membuat folder hanya untuk satu file tanpa alasan.
- Pisahkan concerns.
- Gunakan naming convention konsisten.
- Reuse shared utilities.
- Hindari circular dependency.

## Review

Jika struktur mulai kompleks:

- identify duplicated responsibility
- identify oversized modules
- identify unclear ownership
- propose restructuring
