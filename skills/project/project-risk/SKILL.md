# Project Risk

## Purpose

Mengidentifikasi dan mengelola risiko project.

## Categories

- technical
- security
- dependency
- performance
- compatibility
- scope
- deadline
- data
- deployment

## Risk Levels

- low
- medium
- high
- critical

## Workflow

Identify
→ Assess
→ Mitigate
→ Monitor
→ Resolve

## Rules

Critical risk harus ditangani sebelum release.
