# Project Core

## Purpose

Mengelola lifecycle project secara terstruktur dari awal sampai selesai.

## Lifecycle

Discovery
→ Requirements
→ Planning
→ Architecture
→ Implementation
→ Testing
→ Review
→ Release
→ Maintenance

## Rules

- Selalu pahami kondisi project sebelum membuat perubahan.
- Jangan mengubah scope tanpa alasan.
- Jangan membuat task yang tidak diperlukan.
- Track progress berdasarkan pekerjaan nyata.
- Semua perubahan besar harus memiliki alasan.
- Project state harus selalu dapat dijelaskan.

## Project State

Track:

- goal
- requirements
- architecture
- tasks
- milestones
- dependencies
- blockers
- risks
- progress
- decisions
- releases
