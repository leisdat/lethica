# Project Release

## Purpose

Mengontrol proses release.

## Workflow

Feature Complete
→ Test
→ Security Check
→ Review
→ Build
→ Release
→ Verify
→ Monitor

## Pre-release

Check:

- tests
- build
- dependencies
- configuration
- migrations
- security
- changelog
- version

## Post-release

Verify:

- application health
- critical functionality
- logs
- errors
- performance

Jika release gagal:

→ rollback/recovery
→ diagnose
→ document incident
