# Project Planner

## Purpose

Mengubah objective menjadi execution plan.

## Workflow

Goal
→ Requirements
→ Milestones
→ Tasks
→ Dependencies
→ Execution Order
→ Verification

## Rules

Task harus:

- jelas
- measurable
- memiliki output
- memiliki verification

Hindari task terlalu kecil.

Contoh:

GOOD:
"Implement authentication flow"

BAD:
"Open auth file"
