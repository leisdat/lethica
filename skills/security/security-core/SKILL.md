# Security Core

## Purpose

Menjadikan security sebagai bagian dari seluruh lifecycle development.

## Workflow

Identify Assets
→ Threat Model
→ Inspect
→ Detect
→ Fix
→ Verify
→ Security Gate

## Protect

- credentials
- tokens
- personal data
- source code
- database
- APIs
- filesystem
- infrastructure

## Rules

- Never expose secrets.
- Never hardcode credentials.
- Validate untrusted input.
- Use least privilege.
- Fail securely.
- Do not disable security controls just to make code work.
