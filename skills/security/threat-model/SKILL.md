# Threat Model

## Purpose

Mengidentifikasi ancaman sebelum implementation.

## Analyze

- assets
- entry points
- trust boundaries
- attackers
- attack surface
- sensitive operations

## Questions

- Apa yang bisa diserang?
- Siapa yang dapat mengaksesnya?
- Data apa yang bisa bocor?
- Apa dampak jika component dikompromikan?

## Output

Threat
→ Impact
→ Likelihood
→ Mitigation
