# Messaging Integration

## Supported Patterns

- Discord
- Telegram
- Slack
- email
- chat platforms

## Rules

- Jangan spam.
- Hormati rate limits.
- Validate destination.
- Jangan mengirim secret.
- Pastikan message sesuai context.

Untuk automated notification:

Event
→ Filter
→ Format
→ Send
→ Verify
