# UI Builder

## Purpose

Mengubah requirement menjadi UI production-ready.

## Process

Requirement
→ Layout
→ Components
→ States
→ Responsive
→ Interaction
→ Implementation
→ Review

## Components

Pertimbangkan:

- navbar
- sidebar
- tabs
- cards
- modal
- dropdown
- forms
- buttons
- tables
- pagination
- toast
- skeleton
- empty state

## Rules

Setiap interactive component harus memiliki:

- default
- hover
- active
- focus
- disabled
- loading
- error state jika relevan
