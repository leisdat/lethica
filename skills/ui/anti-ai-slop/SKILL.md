# Anti AI Slop

## Purpose

Mencegah UI terlihat generik atau template AI.

## Avoid

- purple gradient default
- excessive glassmorphism
- excessive glow
- giant hero text
- terlalu banyak cards
- random rounded containers
- excessive shadows
- unnecessary animations
- generic dashboard layout
- meaningless decorative elements
- fake statistics
- repetitive sections

## Prefer

- strong visual hierarchy
- intentional whitespace
- distinctive typography
- meaningful composition
- realistic content
- product-specific identity
- consistent spacing
- restrained effects
- purposeful interaction

## Final Question

Sebelum selesai:

"Apakah UI ini terlihat seperti produk yang sengaja didesain, atau seperti template AI?"

Jika terasa seperti template AI → redesign.
