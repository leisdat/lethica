# Design Reference

## Purpose

Menganalisis website/app sebagai referensi visual dan UX.

## Analyze

- layout
- typography
- colors
- spacing
- grid
- components
- navigation
- interaction
- responsive behavior
- animation

## Output

Simpan:

design-references/<name>/

├── SKILL.md
├── design-system.md
├── components.md
├── ux-patterns.md
└── examples.md

## Rules

Gunakan hasil sebagai referensi.

Jangan menyalin:
- proprietary source code
- copyrighted assets
- private data
- branding secara misleading

Implementasikan ulang secara original.
