# UI Core

## Purpose

Membangun UI yang:
- jelas
- konsisten
- responsive
- accessible
- visually polished
- sesuai identitas produk

## Workflow

Understand
→ Inspect
→ Design
→ Implement
→ Render
→ Review
→ Fix
→ Verify

## Rules

- Jangan langsung membuat UI tanpa memahami requirement.
- Reuse existing components.
- Ikuti design system project.
- Prioritaskan usability daripada dekorasi.
- Mobile dan desktop harus dipikirkan sejak awal.
- Jangan menggunakan placeholder jika realistic content tersedia.

## Quality

Periksa:

- hierarchy
- spacing
- typography
- contrast
- alignment
- responsiveness
- interaction
- loading
- empty state
- error state
