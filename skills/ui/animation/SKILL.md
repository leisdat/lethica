# Animation

## Purpose

Menggunakan animation untuk meningkatkan UX.

## Use For

- transitions
- feedback
- loading
- navigation
- state changes
- visual hierarchy

## Rules

Animation harus:

- purposeful
- subtle
- responsive
- tidak mengganggu usability

Hormati prefers-reduced-motion.

Hindari:
- animation berlebihan
- infinite animation tanpa tujuan
- transition pada semua element
