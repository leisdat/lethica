# Unit Testing

## Purpose

Memverifikasi unit/function secara terisolasi.

## Test

- normal behavior
- boundary values
- invalid input
- error handling
- return values
- side effects

## Rules

Test harus deterministic jika memungkinkan.

Hindari test yang bergantung pada:

- network
- waktu real
- external service

kecuali memang diperlukan.
