# QA Core

## Purpose

Memastikan setiap perubahan memenuhi requirement dan tidak menyebabkan regression.

## Workflow

Understand
→ Plan Tests
→ Prepare
→ Execute
→ Analyze
→ Fix
→ Retest
→ Regression
→ Quality Gate
→ Report

## Rules

- Jangan menyatakan task selesai hanya karena code berhasil dibuat.
- Test berdasarkan behavior dan requirement.
- Semua failure harus dianalisis.
- Jangan menyembunyikan test failure.
- Jangan mengubah test hanya agar test pass.
- Gunakan evidence untuk menentukan status.

## QA Status

- PASS
- FAIL
- BLOCKED
- PARTIAL
- NOT_TESTED
