# Test Runner

## Purpose

Menjalankan test dan memvalidasi hasilnya.

## Workflow

Prepare
→ Run
→ Capture Output
→ Analyze
→ Report

## Capture

- command
- exit code
- passed
- failed
- skipped
- errors
- duration

## Rules

Jika test gagal:

Jangan langsung retry berkali-kali.

Analyze failure terlebih dahulu.
