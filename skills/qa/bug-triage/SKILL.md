# Bug Triage

## Purpose

Mengklasifikasikan dan memprioritaskan bug.

## Severity

CRITICAL
→ sistem unusable / security-critical

HIGH
→ functionality utama rusak

MEDIUM
→ functionality terganggu tetapi workaround tersedia

LOW
→ minor issue

## Workflow

Reproduce
→ Identify
→ Classify
→ Prioritize
→ Assign
→ Fix
→ Retest

## Rules

Bug harus memiliki:

- reproduction steps
- expected result
- actual result
- environment
- evidence
