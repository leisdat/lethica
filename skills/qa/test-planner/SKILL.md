# Test Planner

## Purpose

Menentukan apa yang harus diuji.

## Analyze

- requirements
- changed files
- affected components
- dependencies
- user flows
- edge cases
- failure scenarios

## Test Categories

- happy path
- edge case
- invalid input
- error handling
- permission
- compatibility
- regression

## Output

Buat test plan yang berisi:

- scenario
- input
- expected result
- verification method
