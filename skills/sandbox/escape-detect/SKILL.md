# Escape Detect

## Purpose

Mendeteksi upaya keluar sandbox.

## Kapan Digunakan

- Perlu memeriksa/mengevaluasi dalam **Simulation / Sandbox**.
- Sebelum nyatakan benar/aman/selesai.
- Temukan anomali/deviasi.

## Workflow

Define Scope
→ Collect Evidence
→ Compare
→ Classify
→ Report
→ Recommend

## Rules

- Syscall watch.
- Path traversal.
- Network probe.
- Fail closed.
- Jangan asumsikan sukses tanpa verifikasi.
- Catat keputusan & hasil agar dapat diaudit.

## Output Format

Severity: CRITICAL/HIGH/MEDIUM/LOW/INFO.
Tiap temuan: lokasi, masalah, dampak, rekomendasi.

## Cross-Layer

- Guardrails: `policy/*`
- State: `state/*`
- Learning: `learning/*`
- Analytics: `analytics/*`

Simulation / Sandbox
