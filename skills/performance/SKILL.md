# Performance

## Purpose
Meningkatkan performance berdasarkan evidence.

## Rules

Jangan melakukan optimization hanya berdasarkan asumsi.

## Workflow

1. Measure
2. Identify bottleneck
3. Optimize
4. Measure again
5. Verify behavior

## Check

- CPU
- memory
- disk I/O
- network
- database queries
- rendering
- bundle size
- unnecessary computation
- caching
- concurrency

## Principle

Correctness > Reliability > Security > Maintainability > Performance

Performance optimization tidak boleh merusak behavior atau security.
