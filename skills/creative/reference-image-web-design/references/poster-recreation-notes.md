# Poster recreation notes

## Session lesson

A first attempt used a normal fantasy landing-page hero with invented CSS scenery. The user rated it about 1/10 because the supplied reference was a dense editorial poster: cream paper field, oversized black/outline title, Gamescom-style masthead, several rotated overlapping artwork panels, and a red ticket/event block. The second attempt improved the silhouette by implementing those structural anchors.

## Durable guidance

- The user's primary similarity test is composition, not theme.
- If the supplied poster asset is available, use it directly or crop it into the collage; abstract gradients cannot preserve character artwork.
- Explicitly distinguish an inspired mockup from a close recreation when the original artwork is unavailable.
- Validate syntax and serving separately from visual fidelity; HTTP 200 does not prove the page looks right.
