# Analytics Core

## Purpose

Mengukur aktivitas, performa, reliability, dan efisiensi Lethica.

## Track

- agents
- tasks
- tools
- execution time
- success rate
- failure rate
- retries
- token usage
- estimated cost
- errors
- bottlenecks

## Rules

Analytics harus berdasarkan data nyata.

Jangan membuat metric palsu.

Jangan menyimpan sensitive data yang tidak diperlukan.
