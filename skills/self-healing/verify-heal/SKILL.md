# Verify Heal

## Purpose

Verifikasi pasca-perbaikan.

## Kapan Digunakan

- Perlu memeriksa/mengevaluasi dalam **Self-Healing**.
- Sebelum nyatakan benar/aman/selesai.
- Temukan anomali/deviasi.

## Workflow

Define Scope
→ Collect Evidence
→ Compare
→ Classify
→ Report
→ Recommend

## Rules

- Re-run check.
- Compare baseline.
- Rollback bila gagal.
- Report.
- Jangan asumsikan sukses tanpa verifikasi.
- Catat keputusan & hasil agar dapat diaudit.

## Output Format

Severity: CRITICAL/HIGH/MEDIUM/LOW/INFO.
Tiap temuan: lokasi, masalah, dampak, rekomendasi.
