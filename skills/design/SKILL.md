# Design

## Purpose
Membantu membuat UI/UX yang intentional, refined, dan terasa didesain secara profesional.

## When To Use

- User meminta membuat atau memperbaiki antarmuka.
- Perlu menganalisis desain website sebagai referensi.
- Perlu mendesain berdasarkan product identity.

## Workflow

1. Identify product type
2. Identify target users
3. Identify main task
4. Identify brand personality
5. Identify information density
6. Choose visual language
7. Define hierarchy
8. Build layout
9. Implement components
10. Verify responsive

## Design Reference

Jika folder `design-references/<name>/` tersedia, gunakan sebagai inspirasi:

- design-system.md → tokens (color, type, spacing, radius)
- components.md → pola komponen
- ux-patterns.md → alur interaksi

JANGAN clone 1:1 website sumber. Implementasi ulang secara original.

## Anti Slop Rules

Hindari:

- Gradient ungu/biru berlebihan
- Glassmorphism berlebihan
- Text glowing raksasa
- Blob melayang acak
- Shadow berlebihan
- Neon di mana-mana
- Grid kartu repetitif tanpa makna

Setiap efek harus punya alasan: hierarchy, usability, state, navigation, identity.

## Typography

Bedakan jelas:

- Display
- Heading
- Subheading
- Body
- Caption
- Metadata

## Responsive

Jangan sekadar mengecilkan desktop.

- Reorder konten
- Collapse navigation
- Ubah struktur grid
- Sesuaikan information density
- Touch target nyaman

## Self Review

Sebelum selesai tanya:

1. Apakah ini terlihat seperti website AI generik?
2. Apakah mobile terasa didesain, bukan sekadar dikompres?
3. Bisakah efek dihapus tanpa memperburuk UI?
4. Apakah interface punya identity sendiri?
