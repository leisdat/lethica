## Referensi tersimpan

### Neo Brutalism UI Library
- **Link**: https://www.figma.com/community/file/1613945708230609539/neo-brutalism-ui-library
- **Author**: Basma Gh (basmagh di Figma)
- **License**: CC BY 4.0 (open source)
- **Base**: shadcn/ui neo-brutalism style
- **Konsep**: Bold borders, hard shadows (no blur), minimal rounding, high contrast, "gak ada yang soft"
- **Cocok buat**: Developer tools, dashboard, control panel
- **Gak cocok buat**: Media/streaming app (NOVA), content-heavy

#### Karakteristik utama:
| Aspek | Neo Brutalism |
|-------|--------------|
| Border | Tebal (3-4px solid), kontras tinggi |
| Shadow | Hard shadow — `box-shadow: 4px 4px 0 #000` (tanpa blur) |
| Radius | 0 atau minimal (`4px`) |
| Warna | Monokrom + 1 warna aksen bold |
| Feel | Tegas, developer tool, "berani" |
| Font | Bold weight, sans-serif, display pairing |
