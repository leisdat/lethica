# Refactoring

## Purpose
Meningkatkan struktur code tanpa mengubah behavior.

## Rules

- behavior harus tetap sama
- refactor secara bertahap
- test sebelum dan sesudah
- jangan mencampur refactor besar dengan feature besar
- hapus duplicate code hanya jika memang aman
- jangan membuat abstraction terlalu dini

## Workflow

Inspect
→ Test
→ Refactor
→ Test
→ Review
→ Verify
