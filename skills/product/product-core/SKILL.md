# Product Core

## Purpose

Prioritas fitur, kebutuhan user, roadmap.

## Kapan Digunakan

- Mengoordinasikan skill dalam layer **Product Intelligence**.
- Entry point sebelum sub-skill.
- Menentukan alur antar-step domain ini.

## Workflow

Discover
→ Select
→ Delegate
→ Track
→ Verify
→ Report

## Rules

- User-centric.
- Data-driven.
- Trade-off.
- Roadmap.
- Jangan asumsikan sukses tanpa verifikasi.
- Catat keputusan & hasil agar dapat diaudit.

## Integration

- Di bawah `product-core`.
- Koordinasi `policy` & `state` bila relevan.
- Konsumable `analytics` & `learning`.

## Cross-Layer

- Guardrails: `policy/*`
- State: `state/*`
- Learning: `learning/*`
- Analytics: `analytics/*`

Product Intelligence
