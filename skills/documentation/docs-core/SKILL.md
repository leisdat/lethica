# Documentation Core

## Purpose

Menjaga dokumentasi tetap akurat, jelas, dan sinkron dengan project.

## Workflow

Inspect
→ Identify Changes
→ Update Docs
→ Verify
→ Review

## Rules

- Dokumentasi harus berdasarkan implementation nyata.
- Jangan mengarang fitur.
- Jangan mendokumentasikan behavior yang tidak ada.
- Update docs jika perubahan mempengaruhi user/developer workflow.
- Hindari dokumentasi yang terlalu panjang tanpa manfaat.
