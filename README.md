## ✨ Overview

**Lethica** is an advanced autonomous AI agent system featuring semantic memory, knowledge graphs, adaptive planning, and continuous skill evolution. Built for complex reasoning, multi-step task automation, and intelligent decision-making.

---

## 🔥 Key Features

- **🧠 Semantic Memory**: Long-term knowledge storage with hybrid retrieval
- **⚡ Adaptive Planning**: Multi-candidate exploration (4 parallel paths)  
- **🎯 Skill Evolution**: Auto-improvement from experience (v3.5+)
- **🛠️ 120+ Skills**: Security, MLOps, Software Dev & more
- **🔐 Privacy-First**: Local processing with secret redaction

## 👋 Quick Start

```bash
git clone https://github.com/leisdat/lethica.git
cd lethica
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```
