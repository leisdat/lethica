# 🧹 Clean & Ignore Rules for Lethica AI Agent

## Do NOT commit (already in .gitignore):

### 🔴 SENSITIVE - API Keys & Tokens
- `.rk_key*` - Routerku private keys
- `*.routerku.*.json` - Token caches
- `routerku.log`, `routerku/*.` - Request logs  
- `9router/*` - Alternative router implementations
- `.kiro_tokens.json` - External token data

### 📊 DATA STORES - Generated Databases
- `workspace-index.db` - Indexed workspace DB (132MB)
- `http-cache.db` - HTTP response cache
- `history.json` - Task execution history
- `task-history.json` - Detailed task logs
- `skill-registry.json` - Compiled skill catalog
- `strategy-registry.json` - Strategy outcomes
- `task-failures.json` - Error tracking

### 🗂️ WORKSPACE & SESSIONS - Runtime State
- `workspace/` - 24+ project workspaces (dynamic content)
- `sessions/` - Active chat sessions
- `logs/` - Execution and debug logs
- `memory/` - Semantic memory storage
- `snapshots/` - System state snapshots

### 🧪 TESTS & DEVELOPMENT
- `tests/` - Test suite files (not production code)
- `__pycache__/` - Python bytecode
- `*.pyc`, `*.pyo` - Compiled Python files
- `.pytest_cache/` - pytest metadata

### 💾 BACKUPS - Auto-generated Archives
- `backups/` - Backup directories
- `*.bak`, `*.bak-*` - Backup file variants
- `config.toml.bak*` - Config backups

### 🔍 TEMPORARY FILES
- `deprecated/` - Old/deprecated code
- `.lethica_test/` - Temporary test folders
- `*.tmp`, `*_test.py` - Temporary/test files

## ✅ DO Commit:

### 📝 Documentation
- `README.md` - Main documentation (with animations!)
- `changelog.md` - Version history
- `LICENSE` - MIT License

### ⚙️ Configuration Template
- `config.toml.template` - Example config (if needed)

- `core/` - Memory, Graph, Orchestra, World Model

### 🛠️ Skills Engine
- `skills/core/` - Core capability modules
- **But exclude**: `skills/security/`, `skills/mlops/` etc. if too large

### 🏗️ Build System
- `tests/run_all.py` - Main test runner
- **Important**: Keep test infrastructure only

### 📊 Knowledge Systems
- `graph/nodes.json` - If manually curated (optional)
- `graph/edges.json` - Relationship definitions

## 🎯 Best Practices

### Before Committing:
```bash
# Check what will be committed
git status --short

# Verify no sensitive files staged
git diff --cached | grep -i "token\|key\|password\|secret" && echo "⚠️ Sensitive data detected!"

# Review changes
git diff HEAD
```

### Add Important Changes Only:
```bash
# Add core changes
git add README.md config.toml LICENSE core/ skills/core/ lethica.py

# Never add these by accident!
# git add workspace/ graph/ memory/
```

### Staged Files Checklist:
- [ ] No tokens/API keys
- [ ] No database files
- [ ] No workspace/sessions/logs
- [ ] No test/debug files
- [ ] Documentation updated
- [ ] Changelog updated

## 🔄 When Pushing:

```bash
# Safe push (only committed files)
git push origin main

# Force push ONLY when absolutely necessary
git push --force origin main
```

## 🚨 Emergency Cleanup:

If you accidentally added sensitive files:
```bash
# Remove from index but keep locally
git rm --cached path/to/sensitive/file

# Or remove all accidentally added files
git reset HEAD *.db *.log workspace/ memory/
```
